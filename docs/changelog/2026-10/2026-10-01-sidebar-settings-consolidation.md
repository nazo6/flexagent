# サイドバー新規セッション導線の集約と設定ページへの統合

- **日付**: 2026-10-01
- **対象パッケージ**: `ui`
- **対象スクリプト / 設定**: `docs/05-cli-and-pwa-ui.md` §3.2

## 概要

Web UI のナビゲーションを整理した。

1. **新規セッション導線の重複解消**: サイドバーには新規セッションへの導線が
   3箇所（ヘッダーの `+` アイコン / クイックナビの「新規セッション」/ フッターの
   「新規セッションを開始」ボタン）に存在し、迷いとコード重複の原因になっていた。
   クイックナビの「新規セッション」1箇所へ集約した。
2. **管理系画面の設定ページ統合**: 独立ルートだった「エージェント管理」
   (`/agents`) と「監査ログ」(`/audit`) をサイドバーから外し、設定ページ
   (`/settings`) のタブとして統合した。

## 実装

| ファイル                                             | 内容                                                                                                                             |
| :--------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------- |
| `ui/src/lib/components/layout/AppSidebar.svelte`     | ヘッダーの `+` リンクとフッターの「新規セッションを開始」ボタンを削除し、クイックナビのみに集約。`/agents` / `/audit` ナビを削除 |
| `ui/src/lib/components/settings/AgentManager.svelte` | 新規。`/agents` ページから移設したエージェント管理パネル（ノード選択・インストール・一括更新・削除）                             |
| `ui/src/lib/components/settings/AuditLog.svelte`     | 新規。`/audit` ページから移設した監査ログパネル（一覧・詳細表示）                                                                |
| `ui/src/routes/settings/+page.svelte`                | `Tabs`（全般 / エージェント管理 / 監査ログ）を導入し、両パネルを組み込み                                                         |
| `ui/src/routes/agents/+page.svelte`                  | 削除                                                                                                                             |
| `ui/src/routes/audit/+page.svelte`                   | 削除                                                                                                                             |

## 設計判断

- 両パネルは設定タブのアクティブ時のみマウントされるため、取得 API
  (`GET /api/v1/agents` / `GET /api/v1/audit/logs`) はタブを開くまで発火しない
  （初期表示の API 呼び出しを削減）。
- 旧ルート (`/agents` / `/audit`) は後方互換リダイレクトを設けず削除した
  （DRY 原則。UI 内の参照はサイドバーのみで、外部から参照する仕様もない）。
