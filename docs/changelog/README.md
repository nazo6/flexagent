# Changelog（時系列実装ログ）

確定した変更内容・検証結果を月別ディレクトリ（`YYYY-MM/`）に記録します。

## 記載基準

- **記録するもの**:
  - 新機能の実装完了、DB マイグレーションを伴う変更、複数コンポーネントに影響する変更
  - 設計上の意思決定（なぜこの案を選んだか）や検証結果の記録
- **記録しないもの**:
  - Git コミットログで追える単発のバグ修正、軽微な UI スタイル調整、タイポ修正
- 複数フェーズに跨がる大規模な計画・設計提案は [`docs/proposals/`](../proposals/README.md) に作成してください。
