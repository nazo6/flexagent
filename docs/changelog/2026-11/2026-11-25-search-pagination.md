# 検索結果の追加読み込み

- **日付**: 2026-11-25
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト**: `mise run fmt`, `pnpm --dir ui run check`, `pnpm --dir ui run test`

---

## 概要

全文検索とセッション内検索は常に先頭 50 件だけを表示していた。結果が
50 件以上あるときは `Show more` で取得件数を増やせるようにした。

## 変更

### `ui`

- グローバル検索は 50 件ずつ上限 500 件まで (`GET /api/v1/search` の
  `limit` を増やして再取得)。件数表示を追加した。
- セッション内検索 (`TurnOutline`) は 50 件ずつ上限 200 件まで。
  検索語を変えると 1 ページ目に戻る。
- 追加読み込み中は進捗を表示し、二重クリックを防ぐ。
- `TurnOutline` の「Show more」のテストを追加した。

## 検証

- `pnpm --dir ui run test`
- `pnpm --dir ui run check`
- 手動: 50 件以上ヒットする語句で件数と追加読み込みを確認する
  (開発データではヒット数が少ないため、テストで代替)。
