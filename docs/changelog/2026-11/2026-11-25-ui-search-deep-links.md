# 検索結果から該当メッセージへのジャンプ

- **日付**: 2026-11-25
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト**: `mise run fmt`, `pnpm --dir ui run check`, `pnpm --dir ui run test`

---

## 概要

全文検索のヒットはセッションの先頭へ移動するだけだった。ヒットした
`node_seq` は分かっているのに使っておらず、長いセッションでは該当箇所を
探し直す必要があった。検索結果を `/sessions/{id}?seq={node_seq}` への
ディープリンクにし、セッション画面が古い履歴を読み足しながら該当行まで
スクロールして一度だけ点滅させる。

## 変更

### `ui`

- タイムラインの各行に `data-seq` / `data-seq-end` を付けた。ツール呼び出し
  や作業ブロックは複数イベントを 1 行に畳むため、行が覆う `node_seq` の
  範囲を持たせる。検索は 1 イベントを指すので、範囲に含まれる行を探す。
- セッション画面が `?seq=` を読み、一番新しいページを読み終えてから
  対象が現れるまで `before_cursor` で古いページを追加読み込みする。
  対象が読み込み済みの範囲内にあり、それでも行が無い場合 (折りたたまれた
  イベントなど) はそこで打ち切る。
- 到着した行は `seq-focus` で 1 回だけ点滅させ、追従スクロールは止める。
  以降の出力で勝手に末尾へ戻らない。
- 検索結果のスニペット自体もリンクにした。タイトルだけでなく本文を
  クリックしても同じ位置へ移動する。

## 検証

- `pnpm --dir ui run check`
- `pnpm --dir ui run test`
- 手動: 長いセッションの古いメッセージを検索し、結果から開いて
  対象行が表示・点滅すること。読み込み済みのメッセージでは追加読み込みが
  走らないこと。
