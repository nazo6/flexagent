# Files のツリー + プレビュー化と外側ツールの固定

- **日付**: 2026-11-14
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト / 設定**: `pnpm --dir ui run check`, `pnpm --dir ui run lint`,
  `pnpm --dir ui exec vitest run`, `pnpm --dir ui run build`, `mise run fmt`
- **関連ドキュメント**:
  - [`docs/proposals/2026-11-14-workspace-dock.md`](../../proposals/2026-11-14-workspace-dock.md)
  - [`docs/07-web-ui-and-pwa.md`](../../07-web-ui-and-pwa.md) §3.2

## 背景

Phase 0 では右ペインを可変タブ（Files / Changes / Terminal / File）にしていた。
ファイルを開くたびに外側のタブが増え、ツール切替がファイル一覧に埋もれる。
また、外側タブを閉じる操作と「最後のタブでドックを畳む」規則が、固定された
ツール切替として自然ではなかった。

## 変更

- **外側ツールを固定**: Files / Changes / Terminal の 3 つにした。切替は
  デスクトップのレールとモバイルのセッションヘッダーのアイコンで行う。
  ドックのヘッダーはアクティブツール名 + 閉じるボタンだけを持つ。
- **Files をツリー + プレビューに変更**:
  - プレビュー上部にファイルタブ（可変）を置き、同じパスのタブは再利用する。
  - ファイルタブは × / 中クリックで閉じる。上限は 8。
  - デスクトップはツリーを隠してプレビューを全幅にできる。
  - モバイルはツリー ↔ プレビューを戻るボタンで切り替える。ファイルを開くと
    プレビュー、戻るとツリー。
- **Changes / チャットからの導線**: 行 / tool diff の「Open in dock」は、
  外側の File タブではなく Files ツールのプレビューにファイルを開く（Diff モード）。
- **不要になった UI を削除**: 外側のタブバーとツールシート（`+`）を削除した。
  ドックの開閉はヘッダー / オーバーレイの閉じるボタンで行う。
- **store を v2 に更新**: workspace ごとに `activeTool` / `treeVisible` / `files`
  （path / mode / scope）/ `activeFile` / `collapsed` を保持する。旧 v1 の
  外側タブ状態は読み捨てる。
- **File プレビューの改善**: Git status バッジ、Markdown の Preview / Source、
  長い行でコード背景がスクロール幅に追従する表示を追加した。

## 不変条件

- 外側のツールは固定。外側に可変タブは持たない。
- 可変タブは Files のプレビュー内だけに存在し、パスごとに 1 つ。
- ドックを閉じてもアクティブツール・ファイルタブ・ツリー表示・PTY は保持する。
- モバイルではツリーとプレビューを同時に表示しない（片方だけ）。
- デスクトップではツリーを隠してもプレビューとファイルタブは維持する。

## 検証

- `dock.svelte.ts` のテストを固定ツール / Files 内ファイルタブ / ツリー表示 /
  永続化の形に更新した。
- `pnpm --dir ui run check` / `lint` / `vitest run` / `build` が成功した。

## 既知の制約

- ツリーとプレビューの分割比は固定（ドラッグ変更は未対応）。
- 画像 / Markdown 以外のリッチプレビューは未対応。
- ファイルタブの並べ替え・ピン留めは Phase 3。
