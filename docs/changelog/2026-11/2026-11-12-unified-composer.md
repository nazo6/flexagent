# チャットコンポーザーの統一とセッション設定ダイアログの廃止

- 日付: 2026-11-12
- 対象パッケージ: `ui`
- 対象スクリプト: `pnpm --dir ui check`, `pnpm --dir ui lint`, `pnpm --dir ui test`,
  `mise run fmt`

## 背景

新規セッション画面とセッション詳細画面で、同じ意味の操作が異なる位置・見た目で
提供されていた。

- エージェントモードが新規では「セッション設定」ダイアログ内の `<select>`、
  既存ではツールバーのピルになっていた。
- 新規チャットには添付がなく、既存チャットだけが画像・ノードファイルを添付できた
  （API の `initial_prompt.attachments` は新規でも利用可能だった）。
- 既存チャットのツールバーは折り返し前提で、セレクタとアクションが同じ行に
  混在していた。ボタンが増えると送信ボタンの位置が動いた。
- 「Add or manage agents」がダイアログとエージェントピッカーの両方にあった。
- ノード名がヘッダーとコンポーザーの両方に表示されていた。

## 変更

- `ComposerCard` のツールバーを `selectors`（横スクロール）と `actions`
  （右寄せ・折り返しなし）の2ブロックに分割した。
- 共通の `ModePicker` を追加し、新規・既存の両方で同じモードピルを使う。
  新規は「Default (unspecified)」を含み、`null` を `CreateSessionRequest.mode`
  として送る。
- セッション設定ダイアログ (`SessionSettingsDialog.svelte`) を削除し、各項目を
  もとの文脈へ移した。
  - 追加 CLI 引数 → コンポーザーの `⋯` ポップオーバー（設定時はドット表示）
  - Worktree の base branch → 作業ディレクトリピッカーの新規 Worktree ビュー
  - 手入力エージェント ID → エージェントピッカーの footer
  - Provisioner の clone branch と接続テスト → 環境ピッカー
  - エージェント管理リンク → エージェントピッカーの footer のみ
- 添付ロジックを `composer-attachments.svelte.ts` に抽出し、新規セッションでも
  画像とノードのファイルを添付できるようにした。
- 既存チャットではノードバッジをコンポーザーから外し（ヘッダーと重複）、
  Compact とノードファイル添付を `⋯` メニューへ移した。Auto approve は
  ツールバーに残した。
- `docs/05-cli-and-pwa-ui.md` の「動的コントロールバー」を共通コンポーザーの
  文法（文脈 → 入力 → セレクタ → アクション）に合わせて更新した。

## 不変条件

- 項目が存在しない場合は非表示にするだけで、他の項目の位置は変えない。
- セレクタ行は横スクロール、アクション行は折り返さない。
  これにより送信ボタンは常に右端に固定される。
- エージェント固有の Mode ID は probe の結果だけを使い、推測しない。
- Auto approve と Compact は開始後のセッションにのみ存在し、新規セッションでは
  表示しない。

## 検証

- `pnpm --dir ui check` / `pnpm --dir ui lint` / `pnpm --dir ui test` が成功。
- 1280px / 390px で、新規セッション（添付・`⋯`・手入力 ID）と既存セッション
  （モード・モデル・Auto・`⋯`・送信）を目視確認。ページ全体の横スクロールが
  発生しないことを確認した。
