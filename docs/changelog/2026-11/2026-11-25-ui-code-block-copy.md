# チャットのコードブロックにコピーボタン

- **日付**: 2026-11-25
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト**: `mise run fmt`, `pnpm --dir ui run check`, `pnpm --dir ui run test`

---

## 概要

Markdown のコードフェンスは shiki でハイライトしていたが、内容をコピーする
導線が無く、選択してコピーする必要があった。ブロック右上に Copy ボタンを
重ね、押下後は Copied を短時間表示する。

## 変更

### `ui`

- `highlight.ts` の `enhanceCodeBlocks` が、ハイライト後の `pre` を
  `.fxg-code` で包み `button.fxg-copy` を追加する。読み込み時ではなく
  `{@html}` の描画後に付けるため、サニタイズ対象の HTML は変えない。
- 言語指定の無いフェンス (`<pre><code>`) も対象にした。ハイライトできない
  場合でもコピーだけはできる。
- ボタンはマウスではブロックのホバー / フォーカス時に表示し、タッチでは
  常時表示する。コピー失敗時は既存のエラートーストを出す。

## 検証

- `pnpm --dir ui run check`
- `pnpm --dir ui run test`
- 手動: コードブロックの Copy でクリップボードに入ること、言語指定なしの
  フェンスでもボタンが出ること。
