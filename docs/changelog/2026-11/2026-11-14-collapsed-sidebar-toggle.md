# サイドバー折りたたみ時の左レール廃止と開閉ボタンの一本化

- **日付**: 2026-11-14
- **対象パッケージ**: `ui`
- **対象スクリプト**: `mise run fmt`, `mise run check:ui`, `mise run lint:ui`

## 目的

デスクトップでサイドバーを閉じると、開き直すボタン 1 つだけの全高レールが左端に残り、
メイン領域を無駄に狭めていた。またセッション詳細では、そのレールとヘッダーの両方に
開閉ボタンが表示され、同じ操作が重複していた。

## 変更内容

- `+layout.svelte` から折りたたみ時の固定レールを削除した。
- サイドバーが閉じているときの再表示手段を 1 つに統一した。
  - セッション詳細: `SessionHeader` 左端の既存ボタン。
  - それ以外の画面: メイン領域左上に重ねるフローティングボタン（未対応セッションの
    件数バッジと Problem center バッジを併設）。
- レール専用だった `wco-sidebar-rail` の CSS を削除し、Window Controls Overlay の
  折りたたみ時パディングを「レール幅を差し引く」計算から素直な
  `env(titlebar-area-x)` 基準へ変更した。
- サイドバー折りたたみ時は、セッションヘッダーの Problem center バッジをデスクトップでも
  表示するようにした（サイドバー下部のバッジが見えなくなるため）。
- 再表示ボタンの高さ方向の余白を消費しないため、折りたたみ時のページ内容の
  レイアウトシフトは発生しない。
