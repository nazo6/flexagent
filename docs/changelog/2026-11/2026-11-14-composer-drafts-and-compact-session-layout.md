# コンポーザーの下書き保持とセッション画面の入力欄コンパクト化

- **日付**: 2026-11-14
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト / 設定**: `pnpm --dir ui run check`, `pnpm --dir ui run lint`,
  `pnpm --dir ui run test`, `mise run fmt:oxc`
- **関連ドキュメント**:
  - [`docs/07-web-ui-and-pwa.md`](../../07-web-ui-and-pwa.md) §3.2

## 背景

セッション画面でプロンプトを入力している途中にサイドバーや設定画面へ移動すると、
ルートコンポーネントのアンマウントに伴って入力内容と添付が破棄されていた。また、
セッション詳細の入力欄が既定 3 行分の高さを常に占めるため、狭い画面では会話の
表示領域が圧迫されていた。

## 変更

- **下書きストア (`ui/src/lib/stores/composer-drafts.ts`)**:
  - セッション ID（新規セッション画面は専用キー）ごとにプロンプトと添付を保持する
    アプリ全体のストアを追加。
  - テキストは端末の `localStorage` に保存し、別画面への移動だけでなく再読み込み
    でも復元する。添付はインライン画像のサイズ（最大 10 MiB）を考慮してメモリ内
    のみに保持する。
  - テキストと添付が空になった下書きは破棄し、送信成功時は画面側から明示的に
    クリアする。
- **セッション画面 / 新規セッション画面**:
  - 両コンポーザーが下書きストアを初期値として読み込み、編集内容を書き戻す。
    セッション切り替え時に確実に再初期化するため、セッション画面は
    `{#key sessionId}` でコンポーザーを再マウントする。
  - セッション作成に成功した新規セッション画面は下書きを破棄してから遷移する。
- **レイアウト**:
  - セッション詳細の入力欄を既定 2 行（最小 52px / 最大 160px、内容に応じて
    自動伸長）へ縮小。
  - コンポーザーカードの内側余白とセレクタ行の上余白、入力欄外周とタイムライン
    下端の余白を詰め、会話タイムラインへ縦スペースを配分する。
- **テスト**:
  - `ui/src/lib/stores/composer-drafts.test.ts` を追加（保存・復元・空下書きの
    破棄・明示クリア・利用不可ストレージ）。

## 不変条件

- 下書きは端末ローカルにのみ存在し、ノード / ハブへは同期しない。
- 送信に成功したプロンプトを下書きとして復元しない。
