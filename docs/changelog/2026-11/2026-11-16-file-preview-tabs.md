# Files のプレビュータブ（一時タブ）

- **日付**: 2026-11-16
- **対象パッケージ**: `ui`
- **対象スクリプト / 設定**: `pnpm --dir ui run i18n:compile`, `pnpm --dir ui run test`,
  `pnpm --dir ui run check`, `pnpm --dir ui run lint`, `mise run fmt`
- **関連ドキュメント**:
  - [`docs/07-web-ui-and-pwa.md`](../../07-web-ui-and-pwa.md) §3.2

## 背景

Files のファイルタブはすべて固定タブで、ツリーやチャットのリンクを辿るたびに
タブが増えていた。VS Code のプレビュータブと同じく、閲覧のための一時タブを
1 枚だけ持ち、次のプレビューオープンで置き換えたい。

## 変更

- **ストア（`ui/src/lib/stores/dock.svelte.ts`）**:
  - `DockFileTab` に `preview` を追加し、`openFile` を
    `openFile(path, { mode, scope, line, preview })` に変更した
    （`preview` の既定は `true`）。
  - 既存タブを開き直したときはタブを増やさず、モード・スコープ・行を更新する。
    固定で開き直すとプレビュータブは固定へ昇格する。
  - プレビュータブは常に最大 1 枚。プレビューオープンは既存のプレビュータブを
    同じ位置で置き換え、固定タブは置き換えない。
  - `pinFile(path)` を追加した。`activateFile` はタブを固定しない。
  - プレビュー状態を `localStorage["fxg:workspace_dock"]` に保存し、復元時に
    2 枚目以降のプレビューは固定へ正規化する。既存データに `preview` が
    ない場合は固定として扱う（ストレージのバージョンは据え置き）。
- **UI（`ui/src/lib/components/dock/`）**:
  - プレビュータブのファイル名を斜体で表示し、`title` に
    「ダブルクリックで固定」のヒントを出す。
  - タブのダブルクリックで固定する。プレビューのヘッダーのピンボタンからも固定できる
    （タッチ環境やダブルクリックしにくい環境向け）。
  - Files のツリーと変更一覧、Changes の各行は単クリックでプレビュー、
    ダブルクリックで固定。
  - チャットのファイルリンクとツール diff はプレビューで開く。
- **i18n**: `dock_file_preview_hint` を追加した。

## 不変条件

- プレビュータブは workspace ごとに最大 1 枚。
- 固定タブはプレビューオープンで置き換わらない。
- 同じパスのタブは常に 1 枚で、開き直しは更新とフォーカスのみ。
- タブ上限（8 枚）と workspace ごとの保存は従来どおり。

## 検証

- `dock.svelte.ts` のストアテストに置換・固定・昇格・復元正規化・上限の
  ケースを追加した。
- `pnpm --dir ui run test` / `check` / `lint` が成功した。

## 既知の制約

- ツリーのダブルクリックは先に単クリックが走るため、直前のプレビュータブは
  新しく開くファイルに置き換わってから固定される。クリック遅延を入れて
  単クリックと分ける方式は、通常の単クリックに遅延が出るため採用しない。
