# 左アクセントバーの廃止とステータス表現の統一

- **日付**: 2026-11-14
- **対象パッケージ**: `ui`, `docs`
- **対象スクリプト / 設定**: `mise run fmt:oxc`, `pnpm --dir ui run check`,
  `pnpm --dir ui run lint`, `pnpm --dir ui run test`
- **関連ドキュメント**:
  - [`docs/07-web-ui-and-pwa.md`](../07-web-ui-and-pwa.md) §2 / §3.2

## 背景

選択状態・要対応・承認カード・思考ブロックで共通して使っていた 2px の左アクセント
バーは、装飾的で画面ごとに意味が揺れやすく、セッション行では選択中の塗りと
要対応の塗りが近い色味になり判別しづらかった。

Desk の「ステータスは色だけでなくラベル・アイコンを併記する」「構造は 1px
ヘアラインと面の明度差で作る」という方針に合わせ、左端のバーを廃止し、
選択は面、状態はインラインアイコン・ピル・全面ボーダーで示す。

## 変更

- **サイドバー / ツールレール**:
  - ナビゲーション項目とセッション行から `inset 2px` の左アクセントを削除。
  - 選択中は `signal-soft` の塗りと文字ウェイトのみで示す。
  - 要対応のセッション行はタイトル横に `triangle-alert`（待機）/
    `circle-alert`（エラー）を表示し、既存の状態ピルと併用する。
- **インラインカード**:
  - `PermissionCard` の左バーを削除し、`Permission required` ラベルと
    ツール名をヘッダーに並べる。
  - `ElicitationCard` の左バーを削除し、質問アイコンを `signal` 色にする。
- **チャットの折りたたみ**:
  - `ThoughtBlock` / `ActivityBlock` の左罫線を、1px の全面ボーダーを持つ
    角丸ブロックへ変更する。
- **設定**:
  - `DiagnosticsPanel` のインシデント行の左バーを 1px の全面ボーダーへ変更する。
- **ドキュメント**:
  - `docs/07-web-ui-and-pwa.md` の semantic role とサイドバー仕様から
    左アクセントの記述を削除し、選択・状態の表現方針を追記する。

## 注意（変更しない不変条件）

- `SessionSummary.status` を要対応の単一ソースとする点、待機状態はアーカイブ後も
  表示する点、承認・質問への回答をチャット内で行う点は維持する。
- 色だけに意味を持たせず、ラベルまたはアイコンを併記する。
