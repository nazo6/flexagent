# セッションUIの再整理（ヘッダー・ツールレール・Problems・メッセージアクション）

- **日付**: 2026-11-12
- **対象パッケージ**: `ui`
- **対象スクリプト**: `pnpm --dir ui check`, `pnpm --dir ui lint`,
  `pnpm --dir ui test`, `pnpm --dir ui build`, `mise run fmt`

## 背景

セッションヘッダーにタイトル・メタ情報・Diff/Terminal・Fork・New session here・
Force stop が同居し、幅によってメタ情報が1項目ずつ折り返していた。モバイルでは
共通トップバーとセッションヘッダーの2段になり、エラーは全幅バナーで本文を
押し下げていた。将来ツールやメッセージ単位の操作を増やす前に、情報と操作の
置き場所を整理した。

## 変更

### セッションヘッダー

- 常時表示をタイトル、ステータス、コンテキストピル（ノード名 + ブランチ）、
  `⋯` メニューだけにした。
- パス、プロジェクトID、agent、mode、権限ポリシー、作成・更新時刻、
  コンテキスト使用量、コスト、セッションID、Fork元を **Session details**
  ポップオーバーへ移動した。
- New session here / Force stop / Resume / Rename / Archive / Delete を
  1つの `⋯` メニューにまとめた。
- モバイルはセッション画面だけ共通トップバーを隠し、ヘッダーを1本にした。
- 左サイドバーの常設を `lg` 以上に変更し、それ未満ではドロワーにした。

### ツールレール / パネル

- デスクトップ右端にツールレールを追加し、Diff / Terminal をアイコンで切り替える。
  パネルは従来どおりリサイズでき、幅は localStorage に保存する。
- パネル一覧を `session-panels.ts` のレジストリに集約した。追加ツールは
  レジストリと `SessionPanelHost` の描画分岐だけを増やす。
- モバイルはヘッダーの Tools ボタンからボトムシートを開き、選択したパネルを
  フルスクリーンで表示する。戻るボタンでチャットに戻る。
- Terminal はパネル用の `fill` レイアウトを使い、パネルの高さいっぱいに表示する。

### Problems センター

- 全幅の `ErrorBanner` を削除し、サイドバー下部 / モバイルヘッダーの件数バッジと
  右シートに置き換えた。エラーが増減してもチャットのレイアウトは動かない。
- 各問題の詳細、復旧アクション、Request ID コピー、Dismiss、Clear all を提供する。
- `+layout.svelte` のグローバルエラー監視は `<svelte:window>` に移動し、
  マウント/アンマウントに依存しないようにした。

### メッセージアクション / Fork

- user / agent メッセージの境界（メッセージ間）に Copy / Fork の
  アクション行を追加した。デスクトップはメッセージのホバー / フォーカスで
  フェードインし、最新メッセージの行は常時表示する。タッチ端末は常時表示する。
  行はメッセージ境界に置き、表示を切り替えてもレイアウトが動かないようにした。
- 送信メッセージのタイムスタンプを吹き出し内からメッセージ境界の行へ移し、
  吹き出しの高さを節約した。表示は `cli · HH:MM`、ホバーで完全な日時を表示する。
- Fork 先のセッションでは、コピーされた親の履歴と新しいメッセージの境界に
  「Forked from …」のマーカーを表示し、Fork元のセッションへリンクする。
- `fork_scope` に応じて Fork を制御する。`last` は最新の親メッセージだけ有効、
  それ以前は理由付きで無効。`message` は将来の任意境界 Fork 用。
- セッション実行中は Fork を無効化する。サブエージェント内のメッセージは
  Copy のみ（Forkはトップレベルに限定）。
- Fork は新規セッション画面へ `fork_session` を渡す。`message` スコープでは
  追加で `fork_upto`（`node_seq`）を渡し、`CreateSessionRequest` の
  `up_to_node_seq` に載せる。

## 不変条件

- セッションヘッダーは折り返さず、横スクロールを発生させない。
- デスクトップのヘッダー高さは48px、モバイルはタイトル行 + コンテキスト行の
  約76pxに収める。
- メッセージアクションの表示切替はレイアウト高さを変えない（行は常にフローに
  存在し、opacity だけを切り替える）。
- Problems はレイアウトを押し下げない。
- ツール追加はレジストリ1項目 + ホストの描画分岐で行う。
- Fork は capability (`fork_scope`) とセッション状態だけで可否を決める。

## 追記 (2026-11-13)

- チャットタイムラインのブロック間隔を詰めた。ツール / 思考などのブロック間は
  12px。user / agent メッセージの境界アクション行は通常フローに置き、その
  実測高さがそのままメッセージ下の余白になる（固定の余白値を持たない）。
- 境界アクション行の Copy / Fork が、メタ情報（`cli · HH:MM`）の有無で左右に
  ずれないようにした。行末のメタ情報と同じ幅の不可視スペーサを行頭に置き、
  アクションを常に同じ中央位置へ保つ。狭い画面では不可視側だけが縮み、
  表示中のメタ情報は省略しない。
- 境界アクション行の上辺に 8px の余白を入れ、メッセージ本文とボタンが
  密着しないようにした。
- アクション行のボタンを控えめな outlined スタイルへ変更した。背景は透明、
  枠は薄い `border`、ラベルは muted で、ホバー時だけ前景色と `muted`
  背景になる（影は付けない）。
- ツールコールのグループ見出しと各行を詰め、1行あたりの高さを約36pxから
  約27pxへ削減した（余白・文字サイズ・アイコンを一段小さくした）。

## 検証

- 1440px / 768px / 390px（タッチエミュレーション）でヘッダー、レール、
  パネル、ツールシート、Problems、メッセージアクションを確認。
- `last` スコープで最新メッセージの Fork が有効、以前のメッセージが無効になる
  ことを確認。
- `pnpm --dir ui check` / `lint` / `test` が成功。
